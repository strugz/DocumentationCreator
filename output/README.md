# output/

Generated documentation, separated by mode, one folder per project:

- `output/mode-a/<project-slug>/` — Mode A (existing project, documented from code)
- `output/mode-b/<project-slug>/` — Mode B (new project, documented before it is built)
- `output/mode-c/<project-slug>/` — Mode C (existing project modernized into a new one, planned from its Mode A profile)
